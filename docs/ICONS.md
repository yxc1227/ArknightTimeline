# 图标系统 · 清单与规范

形状数据：`app/Support/Icons.php`（单一信息源）· 渲染入口：`<x-icon>` 组件 · 样式：`public/assets/app.css`「图标」段。

本文回答三件事：**有哪些图标、用在哪、以及新增一个图标要遵守什么**。
注册表与本文档不一致时，以 `Icons.php` 为准并回改本文。

---

## 1. 造型语言（为什么长这样）

图标不是从图标库挑一圈凑数，而是把 `DESIGN.md` §1.4 的视觉母题翻译成 24×24 线稿：

| 母题 | 来源 | 图标上的体现 |
| --- | --- | --- |
| 直角 + 单角斜切 | `.brand__mark` / `.btn--primary` 的 clip-path | 容器类形状（卡片、锁体、状态框）右下角斜切；仅几何体（圆、行星环）允许弧线 |
| 「//」系统分隔符 | `RHODES ISLAND ://` | 出处 = 文档内两道平行斜杠 |
| 「[方括号]」 | `[已校验]`、`[推断]` | 审核台 = 方括号包对勾；一致性告警 = 方括号包脉冲线 |
| 近黑 + 标志黄 | 配色纪律 §1.4 | 图标**不含任何色值**，一律 `currentColor` 跟随文字 |
| 等宽微标签 / 网格底纹 | 「技术化仪表」取向 | 线宽 1.5、端点 square、拐角 miter，小尺寸下保持刻线感 |

**不使用任何官方素材** —— 与整站同一红线。

## 2. 输出格式规范

| 项 | 规定 | 理由 |
| --- | --- | --- |
| 载体 | 视图组件 `<x-icon name="…" />`，内联 SVG | 容器内无 Node、无构建步骤；内联才能被 `currentColor` 染色。**禁止** `<img src="*.svg">` 与手写 `<svg>` |
| 画布 | `viewBox="0 0 24 24"`，安全区 3–21 | 所有图标同一网格，混排时视觉重量一致 |
| 描边 | `stroke-width="1.5"`，`linecap="square"`，`linejoin="miter"`，`fill="none"` | 由组件外壳统一给出，注册表只存内部标记 |
| 颜色 | 只有 `currentColor`，注册表零色值 | 上色权归 CSS；语义色由 `.badge--ok/--warn/--danger/--info` 等既有类带入 |
| 命名 | kebab-case，状态类加 `status-` 前缀、世界类加 `world-` 前缀 | 与 CSS 类命名（`btn--ok`）同构 |
| 无障碍 | 纯装饰默认 `aria-hidden`；承担语义时传 `label` → `role="img"` | 组件内强制，不依赖调用方自觉 |
| 缺名处理 | `Icons::get()` 直接抛异常 | 图标写错名是模板错误，静默空 `<svg>` 只会把问题推迟到肉眼发现 |

## 3. 尺寸规范

基准跟随文字（`1em`），四档，不引入第五档：

| 档位 | 类 | 实际大小（body 14px） | 场景 |
| --- | --- | --- | --- |
| 默认 | 无 | 14px | 按钮、徽章、表格行内动作 |
| `icon--sm` | 12px | `.badge`、时间轴节点、密集表格 |
| `icon--lg` | 16px | 顶栏导航、抽屉页签、`.btn--icon` |
| `icon--xl` | 20px | 空状态引导、页头 |

对齐：默认 `vertical-align: -0.15em`；flex 容器（`.btn` 自带 `gap:7px`）无需额外间距。

## 4. 配色规范

图标本体只有形状，颜色完全由上下文决定 —— 这是刻意设计：整套系统的配色纪律
（近黑中性 + 白 + 标志黄，语义色 ≤4）只在 CSS 变量一处维护。

| 场景 | 做法 |
| --- | --- |
| 常规操作图标 | 放进 `.btn` / `.chip`，颜色随文字自动正确 |
| 状态图标 | 套用对应语义类：`.badge--ok` / `--warn` / `--danger` / `--info`（黄 / 橙 / 红 / 冷青） |
| 主按钮内图标 | `.btn--primary` 是黄底黑墨，图标自动转 `--accent-ink`，无需处理 |
| 世界标识 | 泰拉=源石立方，塔卫二=带环行星；着色跟随 `.chip__dot` 同款纪律：可降饱和，不与标志黄打架 |

## 6. 用法示例

```blade
{{-- 按钮内：flex gap 自动间距，颜色随按钮状态 --}}
<button class="btn btn--sm"><x-icon name="scan"/>全量体检</button>

{{-- 外链：承担语义，必须给 label --}}
<a href="{{ $character->wikiUrl() }}" target="_blank" rel="noopener noreferrer">
    <x-icon name="external" label="前往 PRTS 维基"/>PRTS
</a>

{{-- 状态徽章：语义色由 badge 类带入 --}}
<span class="badge badge--danger"><x-icon name="status-anomaly" class="icon--sm"/>2 条告警</span>

{{-- 空状态：xl 档引导 --}}
<x-icon name="spark" class="icon--xl"/>
```

## 7. 新增图标流程

1. 在 `app/Support/Icons.php` 登记内部标记 + 一行用途注释（分组放对段）；
2. 在本文 §5 对应清单补一行；两处同时改，不允许只改一处；
3. 遵守 §2 全部硬约束（24 网格 / 1.5 线宽 / currentColor / kebab-case）；
4. 若新图标引入了**新的母题**（新的弧线用法、新的填充方式），先在 §1 表格登记母题，再画图标 —— 母题清单是封闭的，这是风格统一 的机制保证。
