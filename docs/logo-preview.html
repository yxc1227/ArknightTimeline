使用规则 // RULES

可以：整枚缩放（矢量，任意尺寸都清晰）；顶栏与站点名同排时保持 28px；在深色区块上用 logo--knockout；单色场景用 logo--ink。
不要：拉伸或压扁（始终等比）；改变方块与字母的配色（黄底墨字是唯一标准色）；给标记加描边、阴影或圆角；把斜切角转到别的角上；在标记上叠加文字或图标。
由来：延续原顶栏「AT」方块的识别度，改为原创几何字形；三处母题（斜切方块、A 的平顶、字组下的基准轴）均取自 docs/DESIGN.md §1.4，不使用任何官方素材。
